# lodekit-common

Shared foundations for lodekit packages. Install it with `pip install lodekit-common`; import it
as `lodekit.common`.

Print the `RunContext` JSON schema with `python -m lodekit.common`.

::: lodekit.common
    options:
      members:
        - RunContext
        - run_context_json_schema
        - COMPONENT_PATTERN
